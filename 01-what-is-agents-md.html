什麼是 AGENTS.md

難度：入門｜閱讀時間：5 分鐘

學習目標

  • 說得出 AGENTS.md 與 CLAUDE.md 是做什麼的
  • 知道一份好規則檔該包含哪些內容
  • 理解它和「Vibe Coding」的差別

一句話定義

AGENTS.md 是放在專案根目錄、專門寫給 AI 看的「專案說明書」。AI 開始工作前先讀它，就知道這個專案的目的、結構與規矩。

CLAUDE.md 是 Claude Code 讀取的同類檔案，用法幾乎一樣。

兩個都想支援？讓 CLAUDE.md 只寫一行 @AGENTS.md，規則只維護一份。

為什麼需要它

Vibe Coding 的重點是「把這一頁做出來」；規則檔的重點是「之後每一頁都用同一套方式做出來」。

只靠對話有 AGENTS.md
風格每次可能不同固定一致
檔名／位置要重複交代寫一次即可
換 AI 或新對話脈絡全部歸零讀檔就接得上

一份好規則檔的內容

  1. 專案目的：這是什麼、給誰看。
  2. 技術限制：能用什麼、不能用什麼。
  3. 檔案結構：哪些東西放哪裡。
  4. 風格規範：顏色、字體、版面。
  5. 新增內容的流程：一步一步，AI 照做就好。
  6. 檢查清單與禁止事項：完成前自我檢查。
常見錯誤：只寫「請做得漂亮」這種模糊句。規則要具體、可檢查，例如「最大寬度 760px」。

重點整理與練習

一句話重點：規則檔讓 AI 從「聽一次話」變成「長期照規矩做事」。

練習：想一個你的小專案，列出它的 3 條「絕對不可以」規則。
