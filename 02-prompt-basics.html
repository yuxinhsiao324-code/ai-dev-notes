提示詞基本功

難度：入門｜閱讀時間：5 分鐘

學習目標

  • 會用四要素組出清楚的需求
  • 知道有了 AGENTS.md 後，提示詞可以多短
  • 能分辨「好需求」與「模糊需求」

四要素

  1. 任務：要 AI 做什麼。
  2. 內容：主題、素材、讀者是誰。
  3. 限制：不能做什麼、字數、風格。
  4. 格式：希望交付成什麼樣子。

範例比較

模糊的需求

幫我做一個網頁介紹 Git。

清楚的需求

新增一課講義：〈Git 入門〉，給完全沒碰過的新手，
包含 commit、branch 兩個概念，各附一個指令範例，
最後一題練習。
專案裡已有 AGENTS.md 時，檔名、版型、風格都不用再說，提示詞只需要講「內容」。

常見錯誤

一次塞太多任務。建議一次只做一件事，確認結果再繼續。
沒有說明限制，AI 就會自己發揮，例如偷偷引入外部套件。

重點整理與練習

一句話重點：好提示詞 = 任務 + 內容 + 限制 + 格式；重複的部分交給 AGENTS.md。

練習：把「幫我做個作品集」改寫成含四要素的提示詞。
