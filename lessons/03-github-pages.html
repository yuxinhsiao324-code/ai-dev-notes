用 GitHub Pages 發佈

難度：入門｜閱讀時間：4 分鐘

學習目標

  • 知道 GitHub Pages 是什麼
  • 能把一個靜態網站推上 GitHub 並公開
  • 知道網址長什麼樣子

一句話定義

GitHub Pages 是 GitHub 提供的免費靜態網站空間：你把 HTML 推上去，它就替你變成網址。

三步驟

1. 建立 Repository 並推上去

git init
git add .
git commit -m "add: 初始專案"
git branch -M main
git remote add origin https://github.com/你的帳號/專案名.git
git push -u origin main

2. 開啟 Pages

Repository → Settings → Pages → Source 選 Deploy from a branch，Branch 選 main、資料夾選 / (root)，按 Save。

3. 等候並開啟網址

約 1–2 分鐘後，網址為：

https://你的帳號.github.io/專案名/
網站打開是空白或樣式跑掉？多半是連結用了 / 開頭的絕對路徑。請改成相對路徑。

重點整理與練習

一句話重點：推上 main 分支、開啟 Pages，靜態網站就有網址了。

練習：把這個專案推上你的 GitHub，並用手機開啟網址確認版面。
